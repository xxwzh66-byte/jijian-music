# 极简music 1.1.2 更新公告

上一个版本：1.1.1。这次换掉启动图标。

## 换了新图标

启动图标从「淡紫渐变底 + 深靛蓝八分音符」换成一排声波竖条。

五根圆角竖条，高度按 0.42 / 0.72 / 1.0 / 0.72 / 0.42 的比例排开，中间那根最高。颜色从中心向外分三层：中心 `#00C7BF`（teal），两侧 `#8CC7BF`（cyan），最外两根 `#96A0DC`（淡紫灰）。底色沿用播放页的深靛蓝渐变，从 `#12102E` 到 `#0D0D1E`。

选这个形状的理由：它一眼是音乐，但不画具体的乐器或音符；对称的五根竖条在 48dp 下仍然分得清；单色剪影就能完整表达，所以 Android 13 的主题图标（monochrome 层）直接用同一套形状取色，不会走样。

旧图标是 6.0 期做的，跟现在的视觉语言没有血缘。新图标和播放页的均衡器、进度条是同一套几何。
