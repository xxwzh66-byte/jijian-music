# 极简music 1.1.4 更新公告

上一版 1.1.3。这一版做的都是减法，只加了一个开关。

## 设置页改成可折叠

四个分组（外观、播放与歌词、音乐库、更新）现在都能点标题收起。默认只展开「外观」，其余收起，一屏能看全所有分组，想调哪项再点开。

顺带合并了两组：原来的「播放」和「歌词」并成一个「播放与歌词」，因为它们本来就是同一件事的两面，分开放反而要多滚一次。分区从五个减到四个。

## 启动时自动检查更新，可以关

以前是固定每 24 小时静默查一次，没有开关。现在设置页「更新」里有一行「启动时自动检查更新」，默认开着，关掉之后只有点「立即检查」才会发起请求。

## 删掉的

**访问令牌**。仓库转成公开后，这个输入框彻底没用了：匿名请求就能拿到 releases，留着它反而误导（忘了填只会看到一句让人去找 GitHub 令牌的报错）。设置页和 `UpdateChecker` 里的 `token` 参数一起删除。

**缺封面筛选**。本地音乐页原来有个「缺封面」筛选按钮，加上列表行右上角的黄色小圆点。实际用下来，本地音乐的内嵌封面读取本来就够全，缺图的是极少数，这个筛选常年空着。移除按钮与角标。

**播放统计里的「不重复曲目」**。统计页顶部原来并排两块：「总播放」和「不重复曲目」。后者只是把当前时间窗内的曲目去重计数，跟下面的排行榜信息重复，看排行榜就知道有多少首。现在只留「总播放」。

## 升级说明

从 1.1.3 覆盖安装，签名与包名未变，数据不受影响。设置项少了一个（访问令牌），其余全部保留。
