# 极简music 1.1.5 更新公告

上一版 1.1.4。这一版只修两件事：找不出没封面的歌、删除留下的残渣。

## 没有封面的歌现在能看见了

以前扫描时，不管专辑有没有封面，每一首都会拿到一个
`content://media/external/audio/albumart/<albumId>` 地址。于是「这首歌有没有封面」
永远答不上来，列表里每张缺失的封面试着解码一次，最后留一个空灰方块。

现在先探一下那个地址能不能打开，打不开就存空值。缺封面的位置画一个音符图标，
看起来是有意为之，不像坏掉。

## 删除的四个漏洞

**队列不知道歌没了。** 文件删掉后队列里的位置还留着，指向一个已经不存在的地址。
下一次按「下一首」正好落在这个空位上，直接报错。现在删除会同步清掉队列里所有
指向它的位置。如果删的正是正在播的那首，播放停下来，不会自己跳到邻居——
删除后突然换歌，看起来像故障。

**待删列表存在内存里。** 系统的删除确认弹窗有时会等很久，进程在这期间被杀，
就会留下「文件已经没了、数据库里还有这一行」。现在这个列表落盘，重启后能自己
对账。

**对账函数写好了却没人调。** `reconcilePendingDeletes()` 一直在，但没有任何地方
调用它。现在每次扫描曲库后都会先跑一遍。

**封面缓存从不清理。** SAF 扫描器写的 `cacheDir/covers/<id>.jpg` 只在第一次写出，
之后永远不删，装得越久堆得越多。现在删除曲目时一并删掉，并且只动自己缓存
目录里的文件，`content://` 那种属于系统媒体库，不碰。
