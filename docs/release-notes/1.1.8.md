# V1.1.8

安装包从 15.15 MB 瘦到 3.38 MB。

## 体积

之前每个版本打的都是「什么都带、什么都不删」的包：九成体积在代码（dex）里，
其中大量是从未被调用到的库代码。这个版本打开了 R8 的压缩与资源裁剪，安装包
**15,883,434 B → 3,543,104 B（-77.7%）**。

体积变小不等于功能变少——一个功能没删。所有需要靠反射或系统按名字找到的类
（数据库、播放服务、备份格式、安装器、图标入口）都在保留清单里，并且用工具逐个
核对了打包后的文件，确认它们确实还在。

## 下载可续传

上一版下载被打断就得从头再来。现在会从已经下好的部分接着下，只取剩下的那段。

- 取消下载不再清空缓存，下次点「下载并安装」直接从断点继续。
- 服务器不支持续传（回整包）、或者本地残留文件比新包还长时，自动丢掉重下，
  绝不拼接——拼出来的包装不上，而且之前一步都不会报错。
- 进度条显示的是真实总量，不会从 0 重新跳。

## 升级说明

包名与签名不变，可从 1.1.7 直接覆盖安装。
