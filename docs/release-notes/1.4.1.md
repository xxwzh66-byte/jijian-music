# 极简music V1.4.1 — 首页减掉两排

`versionCode = 17` · `versionName = "1.4.1"`

这一版没有新功能，只做减法。上一版把首页能加的东西加满了：最上面一个「上次播放」
卡片，下面一排「最近在听」，再下面四张自动合集，然后才是用户自己的曲库。库小的
时候这样挺好看，库养到几百上千首之后，「我点的歌」被推到第三屏。

## 「为你挑的」收起

四张自动合集（最近添加 / 最常播放 / 从未播放 / 很久没听）不再铺在首页。

代码一行没删：

- `local/SmartCollections.kt` —— 纯计算，17 个测试都还在
- `ui/screens/LocalScreen.kt` 的 `CollectionRail` —— 组件还在

`LocalScreen.kt` 顶部有一个开关：

```kotlin
private const val SHOW_SMART_COLLECTIONS = false
```

改回 `true` 就恢复，不用动别的地方。收起而不是删除，是因为这几张架子的判断
（30 天入库、按次数再按时间、一次都没播过时整架为空）本身是对的，只是不该默认
占首页。

## 「最近在听」可以关掉

那一排封面的标题右侧多了一个 X，点了就收走。

它和下面的架子不同：不是用户自己排的东西，所以关掉是**偏好**不是一次性的 UI
状态，落在 `AppSettings.showRecentRail`（DataStore），设置页「音乐库」里有
「首页显示「最近在听」」可以重新打开。

默认开。默认关等于新装用户永远看不到这条回头路——而刚装完应用、曲库刚扫进来的
时候，「最近在听」其实是最有用的一排。

## 测试

411 → **412 项 / 41 个类 / 0 失败**。新增的 1 项在 `SettingsRoundTripTest`：
`theRecentRailIsOnUntilTheUserTurnsItOff`，验默认值与写入往返。
