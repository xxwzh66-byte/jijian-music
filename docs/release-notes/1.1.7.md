# V1.1.7

检查到新版本后，应用自己把安装包下下来装上，不再把你送去浏览器。

## 更新改成应用内完成

- 点「下载并安装」后，APK 直接流式下到应用缓存（不进内存、不占可见存储），
  对话框里显示进度与「已下 / 总大小」。
- 下载完成先对 GitHub 公布的 SHA-256 做校验，不通过就丢弃，不会让你装上一个
  被截断的包。
- 校验通过后交给系统安装器。首次会引导你打开「安装未知应用」权限；授权回来
  点「去安装」即可，不用重新下载。
- 下载中可以随时取消，后台不会继续偷偷下完。

## 顺带修掉的一个隐患

GitHub 的 release 里 debug 包排在正式包前面。旧逻辑取第一个 `.apk`，实际会下到
debug 包——签名不同，装到正式版上必然冲突。现在优先挑不带 `debug` 的那个。

## 设置页变干净了

播放记录历史、记录播放统计、耳机拔出时暂停、优先读取同目录 `.lrc`、启动时自动
扫描……这些开关下面原本各挂一句解释，现在全部去掉，只留标题。删除歌曲确认框里
的两句同类说明也一并删掉。

## 升级说明

包名与签名不变，可从 1.1.6 直接覆盖安装。
