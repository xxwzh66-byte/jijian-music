# 极简music 1.1.6 更新公告

上一版 1.1.5。这一版把「音乐库」补完，顺便把页面之间的跳转和状态管理重做了一遍。

## 专辑和歌手有了自己的页面

以前点一个专辑，就是把整张专辑从第一首开始播。分组数据早就在那儿了
（封面、曲目数、总时长都算好了），只是一直没有页面可以落。

现在点专辑或歌手会进入它的页面：大封面、歌手名、「N 首 · 总时长」、
带曲目序号的曲目表，下面两个按钮——播放全部、随机播放。

顺带说清楚一件事：这个页面记的是分组的**名字**，不是那个分组对象。因为
搜索框每敲一个字，分组就会重算一遍；如果记的是对象，你一边看专辑一边去搜歌，
回头会发现曲目表是旧的。

## 备份和恢复

设置里多了「备份」一栏。

导出会把收藏、歌单、播放记录、播放统计和 16 项偏好设置打成一个
`.jjmbackup` 文件（其实就是个 zip），用系统的文件选择器挑位置存，不需要存储权限。

**恢复是合并，不是覆盖。** 收藏、歌单、历史都会加进去，不会删你现有的东西。
同名歌单会合并，新曲目接在后面。

有一个坑必须处理：歌曲的 id 是 `content://` 地址，换台设备就全变了。
所以恢复时靠「标题 + 歌手 + 专辑 + 时长」重新认歌，时长按秒取整——
同一首歌两次抓轨常差几毫秒，严格比较会把它们当成两首。恢复完会告诉你
「恢复 120 首（110 精确 / 10 指纹匹配），缺失 3 首」。

**不跟着走的东西**，都是有意的：扫描目录（换设备后系统授权失效）、
待删除列表（那是另一台设备的删除意图）、上次播放的曲目（可能这台机器上没有）。

## 这一年

播放统计页多了一张「这一年」卡片：播了多少次、总共多少小时、多少首歌、
听得最多的歌手、单曲循环最多的那一首。

它没有入口按钮。一年是一个关于你的事实，不是一个需要点开的功能。
没数据的时候它不出现。

## 顺手修的几件事

**六个布尔值换成了一个页面栈。** 设置、文件夹、统计、队列、均衡器、播放页
原来各自是一个开关，一半在 ViewModel 一半在 `LxApp` 里。专辑页是第一个需要
带参数的页面（「打开名字是 X 的那个专辑」不是一个开关能表达的），于是整个换成
了带类型的栈。返回键关的是**当前看得见的最上层**，不是最后打开的那个。

**`MainViewModel` 从 887 行降到 508 行。** 它原来一个人管扫描、播放、音乐库、
统计、更新、删文件，还直接去 `LxApp.instance` 拿设置。现在拆成五个 store，
它只做转发。屏幕和组件的 import 一行都没动。

**删掉一批死代码。** `song_list` / `list_item` 两张表（在线音源时代的遗留，
零调用，Room 升到 v6 时删表）、`MusicInfo.qualitys` 和 `QualityInfo`（零引用）、
还有声明了却从没用过的 `navigation-compose` 依赖。

## 测试

237 → **273 项，29 个类，全绿**。新增的三个类：备份编解码 15 项、
页面栈 11 项、年度回顾 10 项。备份那一组完全跑在 JVM 上，
不需要模拟器，因为它刻意不碰 `android.net.Uri`。
