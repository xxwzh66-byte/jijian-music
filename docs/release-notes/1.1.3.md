# 极简music 1.1.3 更新计划

当前版本 1.1.2。这一版做两件事：把主界面骨架换成「舞台与幕布」，以及删掉一批已经没人用的代码和设置。

启动图标保持 1.1.2 的五根脉冲条，不动。

---

## 主界面骨架：舞台与幕布

### 现在的问题

`ui/LxApp.kt` 有 606 行。里面五个全屏页面各写一遍同样的三行：

```kotlin
if (settingsOpen) {
    BackHandler { viewModel.closeSettings() }
    SettingsScreen(...)
    return
}
```

`settingsOpen`（:125）、`folderManagerOpen`（:135）、`statsOpen`（:141）、`showQueue`（:146）、`showEqualizer`（:151）五处。加第六个全屏页要重复第六遍，忘写 `BackHandler` 就变成返回键直接退出 app。

这五个 `return` 还和后面的宽屏双栏逻辑（≥840dp 时播放页进右栏）缠在同一个函数体里，改一处要通读全篇。

### 改动

新建 `ui/shell/LxShell.kt`，把壳层收成四个槽位：

| 槽位 | 内容 |
| --- | --- |
| `backdrop` | 极光背景，永远在最底层 |
| `tabs` | 主界面内容（正在听 / 音乐库） |
| `dock` | 底部迷你播放条 |
| `spotlight` | 宽屏右栏播放页 |

全屏页注册成「幕布」：

```kotlin
LxShell(
    backdrop = { AuroraBackdrop(colors = aurora) },
    tabs = { ... },
    dock = { MiniPlayer(...) },
    spotlight = { NowPlayingScreen(...) },
) {
    curtain("settings", viewModel.showSettings) { SettingsScreen(...) }
    curtain("folders", viewModel.showFolderManager) { FolderManagerScreen(...) }
    curtain("stats", viewModel.showStats) { StatsScreen(...) }
    curtain("queue", showQueue) { QueueScreen(...) }
    curtain("eq", showEqualizer) { EqualizerScreen(...) }
}
```

`curtain` 内部做三件事：接管 `BackHandler`、处理进场/退场动画、压入栈。页面自己不再写返回键。

### 边界

- **只改壳**。五个页面的内部结构一行不动，签名保持 `(viewModel, onBack)`。
- `LxApp.kt` 重写，现有页面调用点全部保留。
- 极光配色、封面提色（`ArtworkColors.schemeFor`）、公告条留在宿主，不进框架——这些是每次调用都可能不同的策略。
- 窄屏（<840dp）`spotlight` 槽位为空，行为与现在一致。
- 全屏页多一个进场动画（淡入 + 轻微上移 12dp），返回时反向。动画走 `NeonMotion` 现有的时长常量。

### 验收

1. 五个全屏页各自打开、返回键关闭，行为与 1.1.2 一致。
2. 打开全屏页期间来电话/切后台再回来，页面仍在。
3. ≥840dp 宽屏下播放页仍进右栏，不弹全屏。
4. `LxApp.kt` 从 607 行降到 200 行（实测 200 行；顶栏/公告条/迷你播放条/舞台正文移入 `ui/HomeChrome.kt` 373 行，`ui/shell/LxShell.kt` 132 行）。
5. 现有 230 项单测全绿（壳层无单测，靠实机验证）。

预计新增 `ui/shell/LxShell.kt` 约 240 行，`LxApp.kt` 净减 300 行左右。

## 删掉的死代码

### 零引用的界面组件

`ui/neon/GlassSurface.kt` 里的 `NeonPanel`、`ui/neon/NeonShell.kt` 里的 `NeonHalo`，全项目没有一处调用。同文件的 `Modifier.neonGlass`（7 处用）和 `Modifier.neonChip`（9 处用）是活的，留着。

### 队列的随机分支

`player/QueueLogic.kt` 里的 `nextIndex` / `prevIndex` 两个函数，生产代码一次没调过——真正的下一首/上一首早就走 `PlayerController` + `RandomShuffleState` 了。跟着删掉锁它们的四个测试。`move` / `remove` 是活的，留着。

### 音质设置整套

在线播放删掉之后，「音质」就没有消费对象了：字段恒等于默认值，设置页那行入口在 1.1.0 就删了控件只剩注释。这次把 `AudioQuality` 枚举、`quality` 字段、`setQuality` 方法和它对应的三个测试断言一起清掉。

### 高级区两个滑杆

卡住判定阈值、缓冲超时阈值——这两个是查播放卡死时加的调试参数，占着一整屏。滑杆删了，阈值回默认（8 秒 / 20 秒）。已经存过的旧值仍然生效，不会因为界面没了就被覆盖。

### 自定义音源残留

`user_api` 表（自定义音源脚本的存储）、`examples/example-source.js`。在线音源 1.1.0 已删，这两样跟着作废。数据库升到 v5，迁移里直接把表 drop 掉。

## 顺带修的 bug

「耳机拔出时暂停」这个开关之前是假的：不管开还是关，拔掉耳机都会暂停。`MainActivity` 收到系统广播就无条件暂停，从头到尾没读过这个设置。现在接上了。
